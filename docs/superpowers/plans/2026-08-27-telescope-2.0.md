# Telescope 2.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rebuild Telescope's request-scoping, configuration, and mounting on modern Node primitives, fixing two concurrency bugs, and add Drizzle-backed query capture.

**Architecture:** An `AsyncLocalStorage` request context replaces the shared mutable `batchId` field and the module-scoped axios request slot, closing both concurrency bugs with one construct. Configuration moves from static class properties onto a resolved per-instance object threaded to watchers. The client mounts as an Express `Router` at a caller-chosen prefix, with `index.html` templated at serve time.

**Tech Stack:** TypeScript 5.9 (ESM-only), Node >=22, Express 4, Jest 30 + ts-jest, supertest, drizzle-orm (optional peer).

**Spec:** `docs/superpowers/specs/2026-08-27-telescope-2.0-design.md`

## Global Constraints

- ESM-only. Every relative import ends in `.js`. No CJS build, no `dist/cjs`.
- `engines: {"node": ">=22"}`.
- No `enum` and no constructor parameter properties anywhere in `src/` — the
  source must remain erasable-syntax clean.
- `drizzle-orm` is a `peerDependencies` entry with
  `peerDependenciesMeta: {"drizzle-orm": {"optional": true}}`. It must never
  be imported from the main entry point.
- Slow-query threshold default: `100` (ms).
- Entry content shape for queries is fixed by the existing UI and must be
  exactly `{sql, bindings, time, slow, connection}`.
- The 31 existing tests are the regression net. Where a task changes the
  public API, that task migrates the affected tests in the same commit and
  preserves their behavioural assertions. Never delete a test to make a
  change pass.

```ts
import {AsyncLocalStorage} from "node:async_hooks"

export interface TelescopeContext
{
    batchId: string
    clientRequest?: unknown
}

export const telescopeContext = new AsyncLocalStorage<TelescopeContext>()

export function runWithContext<T>(context: TelescopeContext, fn: () => T): T
{
    return telescopeContext.run(context, fn)
}

export function currentContext(): TelescopeContext | undefined
{
    return telescopeContext.getStore()
}

export function currentBatchId(): string | undefined
{
    return telescopeContext.getStore()?.batchId
}
```

```ts
import {NextFunction, Request, Response} from "express"
import {Driver} from "./DB.js"
import {GetUserFunction} from "./watchers/RequestWatcher.js"
import LowDriver from "./drivers/LowDriver.js"

export interface TelescopeOptions
{
    enabledWatchers?: unknown[]
    databaseDriver?: Driver
    responseSizeLimit?: number
    paramsToHide?: string[]
    ignorePaths?: string[]
    clientIgnoreUrls?: string[]
    ignoreErrors?: ErrorConstructor[]
    isAuthorized?: (request: Request, response: Response, next: NextFunction) => void
    getUser?: GetUserFunction
    enableClient?: boolean
    path?: string
    slowQueryThreshold?: number
    timezone?: string
}

export interface ResolvedConfig
{
    databaseDriver: Driver
    responseSizeLimit: number
    paramsToHide: string[]
    ignorePaths: string[]
    clientIgnoreUrls: string[]
    ignoreErrors: ErrorConstructor[]
    isAuthorized: (request: Request, response: Response, next: NextFunction) => void
    getUser?: GetUserFunction
    enableClient: boolean
    path: string
    slowQueryThreshold: number
    timezone: string
}

function defaultIsAuthorized(request: Request, response: Response, next: NextFunction): void
{
    if (process.env.NODE_ENV === "production") {
        response.status(403).send('Forbidden')

        return
    }

    next()
}

export function resolveConfig(options: TelescopeOptions = {}): ResolvedConfig
{
    return {
        databaseDriver: options.databaseDriver ?? LowDriver,
        responseSizeLimit: options.responseSizeLimit ?? 64,
        paramsToHide: options.paramsToHide ?? ['password', 'token', '_csrf'],
        ignorePaths: options.ignorePaths ?? [],
        clientIgnoreUrls: options.clientIgnoreUrls ?? [],
        ignoreErrors: options.ignoreErrors ?? [],
        isAuthorized: options.isAuthorized ?? defaultIsAuthorized,
        getUser: options.getUser,
        // `?? true` is required: `enableClient: false` must survive.
        enableClient: options.enableClient ?? true,
        path: (options.path ?? 'telescope').replace(/^\/+|\/+$/g, ''),
        slowQueryThreshold: options.slowQueryThreshold ?? 100,
        timezone: options.timezone
            ?? Intl.DateTimeFormat().resolvedOptions().timeZone,
    }
}
```

```ts
import {existsSync, readFileSync} from "node:fs"
import {dirname, join} from "node:path"
import {fileURLToPath} from "node:url"
import {ResolvedConfig} from "./config.js"

export function resolveClientDir(): string
{
    // dist/esm/api/client.js -> dist/
    const here = dirname(fileURLToPath(import.meta.url))

    const candidates = [
        join(here, '..', '..'),
        join(here, '..', '..', '..', 'dist'),
    ]

    const found = candidates.find(dir => existsSync(join(dir, 'index.html')))

    if (!found) {
        throw new Error(
            `Telescope client assets not found. Looked in: ${candidates.join(', ')}`
        )
    }

    return found
}

export function renderIndex(html: string, config: ResolvedConfig): string
{
    const globals = JSON.stringify({
        path: config.path,
        timezone: config.timezone,
        recording: true,
```

```ts
import WatcherEntry, {WatcherEntryCollectionType, WatcherEntryDataType} from "../WatcherEntry.js"
import {currentBatchId} from "../context.js"

export interface QueryWatcherData
{
    sql: string
    bindings: unknown[]
    time: number
    slow: boolean
    connection: string

export class QueryWatcherEntry extends WatcherEntry<QueryWatcherData>
{
    constructor(data: QueryWatcherData, batchId?: string)
    {
        super(WatcherEntryDataType.queries, data, batchId)
    }

export interface RecordedQuery
{
    sql: string
    bindings?: unknown[]
    time: number
    connection?: string

    {
        const entry = new QueryWatcherEntry({

            bindings: query.bindings ?? [],
            time: query.time,
            slow: query.time >= config.slowQueryThreshold,
            connection: query.connection ?? 'default',
        }, currentBatchId())

        await DB.queries().save(entry)
    }
}
```

- [ ] **Step 4: Implement the wrapper**

```ts
import QueryWatcher from "../api/watchers/QueryWatcher.js"
import Telescope from "../api/Telescope.js"

const TIMED_METHODS = ['execute', 'all', 'get', 'run', 'values'] as const

export function wrapDrizzle<T extends object>(db: T, telescope: Telescope): T
{
    return new Proxy(db, {
        get(target, property, receiver) {
            const value = Reflect.get(target, property, receiver)

            if (typeof value !== 'function') {
                return value
            }

            if (!TIMED_METHODS.includes(property as typeof TIMED_METHODS[number])) {
                return value
            }

            return async (...args: unknown[]) => {
                const start = process.hrtime.bigint()

                try {
                    return await value.apply(target, args)
                } finally {
                    const time = Number(process.hrtime.bigint() - start) / 1_000_000

                    const [sql, bindings] = args

                    await QueryWatcher.record({
                        sql: typeof sql === 'string' ? sql : String(sql),
                        bindings: Array.isArray(bindings) ? bindings : [],
                        time: Math.round(time * 100) / 100,
                        connection: 'drizzle',
                    }, telescope.config)
                }
            }
        },
    })
}
```

Recording in `finally` means failed queries are still captured, which matches
what the Exceptions screen pairs against.
